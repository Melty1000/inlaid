# Inlaid v0.2.0-beta.1

This beta keeps the downloadable release on Windows while bringing the new portable capture architecture into the source tree.

## What changed

- The live cell pipeline does less copying and allocation while preserving the terminal image used by snapshots and recordings.
- Double-clicking `inlaid.exe` from Windows Explorer now opens it in Windows Terminal without inserting a shell. Launching from another truecolor terminal still respects that terminal.
- The new **Report** control creates a bounded local JSON report after a second confirmation. It includes typed compatibility and performance facts, but no image data, filesystem paths, device IDs, raw logs, environment dump, or upload.
- Recording and recovery now handle queue pressure, damaged tapes, output collisions, and interrupted cleanup more carefully.
- Experimental native V4L2 and AVFoundation camera paths are present for Linux and macOS source builds.
- Bubble Tea is updated to 2.0.9, including upstream terminal redraw fixes.

## Verified here

The Windows build was exercised on Windows 10 22H2 in Windows Terminal with a Logitech C922 at 1920×1080 and approximately 29.9 FPS. Live preview, PNG, MP4, GIF, close/reopen, recording queue pressure, and direct Explorer launch were checked.

Linux and macOS builds are checked in native GitHub Actions jobs, but their camera paths still need physical hardware testing. See the [compatibility tracker](https://github.com/Melty1000/inlaid/blob/v0.2.0-beta.1/docs/COMPATIBILITY.md) and submit a [compatibility report](https://github.com/Melty1000/inlaid/issues/new?template=02-compatibility-report.yml) if you can test either platform.

## Install

1. Download `inlaid-v0.2.0-beta.1-windows-amd64.zip` and `SHA256SUMS.txt` below.
2. Check the ZIP against the published SHA-256 value.
3. Extract the complete ZIP.
4. Double-click `START-INLAID.cmd`.

The executable is unsigned. FFmpeg is not bundled and is needed only for MP4 and GIF export. The Windows camera path currently requires a native MJPEG mode, and recordings do not include audio.

Read the [full changelog](https://github.com/Melty1000/inlaid/blob/v0.2.0-beta.1/CHANGELOG.md) before upgrading.
